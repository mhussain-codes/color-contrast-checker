# Color Contrast Checker

A small, privacy-friendly tool for checking text and background color pairs against WCAG contrast thresholds. It runs entirely in your browser and uses no dependencies.

## Features

- Live contrast ratio and sample text preview
- WCAG AA normal, AA large, and AAA normal text checks
- Hex input plus native color pickers
- Swap colors, try starter palettes, and copy CSS values
- Responsive layout with keyboard-visible focus styles

## Use it

Open [index.html](./index.html) in a modern browser. Change either color using the picker or enter a 3- or 6-digit hex value. The preview and result update as you edit.

## Contrast thresholds

- AA normal text: 4.5:1
- AA large text: 3:1
- AAA normal text: 7:1

This is a quick design aid. Check all interface states and confirm conformance against the relevant WCAG criteria in context.

## Built with

HTML, CSS, and vanilla JavaScript. No build step or third-party service.
